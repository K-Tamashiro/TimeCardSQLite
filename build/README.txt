1. ソフトの概要
----------------------------------------------------------------------
「Personal TimeCard for Free Lance」は、フリーランス・個人事業主向けの
完全スタンドアロン型 勤怠管理・請求書発行アプリです。

外部サーバーやデータベースの構築は不要で、アプリを起動するとローカル
サーバーが立ち上がり、お使いの Web ブラウザからそのまま利用できます。
データはお使いの PC 内の SQLite3 ファイルに安全に保存されます。

【主な特徴】
- 完全スタンドアロン動作（SQLite3・オフライン利用可）
- 出退勤入力・定時刻印・定時一括入力・早出カウント対応
- 契約履歴ごとの単価・上下限時間・控除/超過単価・消費税率・稼働日設定
- 契約締日（最終稼働日）の自動判定と一覧・入力ポップアップへの表示
- 支払期限設定（翌月/翌々月/3ヶ月後・営業日調整）と請求書印刷（PDF出力）
- 年度休日カレンダー（クリック即登録・連続登録対応）・共有/個人予定カレンダー
- CSV インポート / エクスポート
- 3権限ロール管理（システム管理者 / 管理者 / ユーザ）
- 初回起動時の架空サンプルデータ自動投入＆サンプルのみ安全リセット機能

2. 動作環境
----------------------------------------------------------------------
- OS：Windows 10 / Windows 11（64bit）
- ブラウザ：Microsoft Edge / Google Chrome / Firefox 等のモダンブラウザ
- Python やデータベースソフトの事前インストールは不要です。

----------------------------------------------------------------------
3. インストール・起動方法
----------------------------------------------------------------------
【インストーラー版（PersonalTimeCard-Setup-1.1.0.exe）】
1. ダウンロードしたインストーラーを実行し、画面の指示に従って
   インストールします（管理者権限は不要です）。
2. スタートメニューまたはデスクトップのショートカットから
   「Personal TimeCard for Free Lance」を起動します。
3. 小さな管理ウィンドウが表示され、自動でブラウザが開きます。

【ZIP ポータブル版（PersonalTimeCard-1.1.0-win64.zip）】
1. ZIP ファイルを任意のフォルダに展開（すべて展開）します。
2. 展開されたフォルダ内の「PersonalTimeCard.exe」を実行します。
3. 小さな管理ウィンドウが表示され、自動でブラウザが開きます。

※ 初回起動時に Windows Defender SmartScreen の警告画面
  （「Windows によって PC が保護されました」）が表示される場合があります。
   個人開発の未署名アプリのため表示されるものであり、
  「詳細情報」→「実行」の順にクリックすると起動できます。

【終了方法】
管理ウィンドウの「終了」ボタン（または右上の × ボタン）を押して
終了してください。

----------------------------------------------------------------------
4. データの保存先・バックアップ
----------------------------------------------------------------------
勤怠・設定・請求書データは、以下のフォルダ内の SQLite3 ファイルに
保存されます。

  %LOCALAPPDATA%\PersonalTimeCard\timecard.db

管理ウィンドウの「データフォルダを開く」ボタンから直接開けます。
PC 移行やバックアップの際は、アプリ終了後にこの「timecard.db」を
コピーしてください。

----------------------------------------------------------------------
5. アンインストール方法
----------------------------------------------------------------------
【インストーラー版】
Windows の「設定」→「アプリ」→「インストールされているアプリ」から
「Personal TimeCard for Free Lance」をアンインストールするか、
スタートメニュー内の「アンインストール」を実行してください。

【ZIP ポータブル版】
展開したフォルダごと削除してください（レジストリは使用しません）。

※ 大切な勤怠データを誤って消さないため、アンインストール時も
   %LOCALAPPDATA%\PersonalTimeCard フォルダ内のデータは自動削除されません。
   データも含めて完全に削除したい場合は、上記フォルダを手動で削除してください。
